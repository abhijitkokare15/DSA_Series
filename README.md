# DSA Series

This repository contains a collection of C++ programs focused on Data Structures and Algorithms (DSA) practice. It includes implementations of arrays, searching, sorting, recursion, trees, graphs, stacks, queues, linked lists, hash tables, and common interview-style problems.

## Contents

The repository covers topics such as:

- Arrays and Strings
- Sorting and Searching
- Recursion and Backtracking
- Linked Lists
- Stacks and Queues
- Trees and Binary Search Trees
- Graphs
- Heap
- Trie
- Hashing
- Dynamic Programming / problem-solving patterns

## Repository Structure

- `BST/` — Binary Search Tree related programs
- `Backtracking/` — Backtracking problems
- `Graph/` — Graph algorithms and graph problems
- `Heap/` — Heap implementations and heap-based problems
- `Trie/` — Trie data structure programs
- `Sheets/` — Practice/problem sheet files
- Many root-level `.cpp` files for standalone DSA practice questions

## How to Run

Compile any C++ file using:

```bash
g++ filename.cpp -o output
./output
```

Example:

```bash
g++ binary_tree.cpp -o binary_tree
./binary_tree
```

## Notes

- This repository is primarily for learning and practice.
- Many files are standalone problem solutions and may be written in a beginner-friendly style.
- Some files include executable outputs like `.exe` files as generated artifacts.

## Purpose

The goal of this repository is to help practice and improve problem-solving skills in C++ for coding interviews, competitive programming, and academic data structure learning.
